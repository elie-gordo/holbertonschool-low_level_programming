# C - Dynamic Analysis

## 1) But du projet

Ce projet entraine l observation d un programme en execution avec GDB:

- arreter l execution a des instants precis
- lire les variables runtime sans modifier le code
- produire des valeurs exactes dans un format strict

## 2) Fichiers livrables

- `gdb_fundamentals.txt`
- `gdb_vsc.txt`

## 3) Contraintes appliquees

- aucune modification de `sample.c` pendant l extraction
- aucune instrumentation (`printf`, logs) ajoutee
- valeurs obtenues uniquement par inspection runtime
- format hexadecimal strict conforme aux enonces
