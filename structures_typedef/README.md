# C - Structures, typedef

## 1) But du projet

Ce projet introduit les structures et le typedef en C.

## 2) Regles obligatoires

- Ubuntu 20.04
- Compilation: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Tous les fichiers finissent par une nouvelle ligne
- `README.md` obligatoire dans ce dossier
- Style Betty obligatoire
- Pas de variable globale
- Maximum 5 fonctions par fichier
- Fonctions standard autorisees: `printf`, `malloc`, `free`, `exit`
- Tous les headers doivent etre include guarded

## 3) Fichiers du projet

- `dog.h`
- `1-init_dog.c`
- `2-print_dog.c`
- `4-new_dog.c`
- `5-free_dog.c`

## 4) Exercices realises

- Exercice 0: definition de `struct dog`
- Exercice 1: `init_dog`
- Exercice 2: `print_dog`
- Exercice 3: `typedef dog_t`
- Exercice 4: `new_dog`
- Exercice 5: `free_dog`
