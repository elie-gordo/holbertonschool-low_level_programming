# C - Singly linked lists

## 1) But du projet

Ce projet introduit les listes chainees simples en C:

- parcourir une liste
- compter ses elements
- ajouter un noeud en tete
- ajouter un noeud en fin
- liberer toute la liste

## 2) Regles obligatoires

- Ubuntu 20.04
- Compilation: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- README obligatoire dans le dossier du projet
- Style Betty obligatoire
- Pas de variables globales
- Maximum 5 fonctions par fichier
- Prototypes dans `lists.h`

## 3) Fichiers

- `lists.h`
- `0-print_list.c`
- `1-list_len.c`
- `2-add_node.c`
- `3-add_node_end.c`
- `4-free_list.c`
